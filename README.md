# スイング・スクリーナー

東証の全上場銘柄(プライム・スタンダード・グロース)の前日終値データから、スイングトレードの候補を絞り込むiPhone向けWebアプリです。

- 平日18:30(日本時間)に GitHub Actions が自動でデータを更新します(混雑時は数十分遅れることがあります)
- 株価データは Yahoo Finance から非公式な方法(yfinance)で取得しています。仕様変更で取得できなくなることがあります
- 投資判断はご自身の責任で行ってください

## ファイル
| ファイル | 役割 |
|---|---|
| index.html | スクリーナー画面・チャート分析画面 |
| screener.py | 株価の取得と指標の計算 → site/ に公開用ファイルを出力 |
| analysis.py | サポレジ・トレンドライン・フィボナッチ・パターン判定 |
| .github/workflows/update.yml | 自動更新の設定 |
| requirements.txt | 必要なライブラリ |
| icon.png | ホーム画面用アイコン |

## 指標の意味
- 出来高倍率:前日の出来高 ÷ その前20日の平均出来高
- 売買代金:株価 × 出来高(億円)。絞り込みには20日平均を使用
- 25日線乖離:終値が25日移動平均からどれだけ離れているか(%)
- 25日線が上向き:25日移動平均が5営業日前より上
- パーフェクトオーダー:5日線 > 25日線 > 75日線
- 20日高値/52週高値更新:終値が直前20日/約1年間の高値を上回った
- RSI:14日。70以上は買われすぎ、30以下は売られすぎの目安
- サポート/レジスタンス:過去の山・谷が集まっている価格帯(接触回数が多いほど強い目安)
- トレンドライン:直近の安値(高値)2点を結び、その後ほぼ割れていない線
- フィボナッチ:直近の高値・安値の間の23.6/38.2/50/61.8/78.6%の水準
- パターン:ダブルボトム/トップ、三角保ち合い、ボックス、高値・安値の切り上げ/切り下げを機械的に判定
